# BOOMZ THAI EDITION — Prototype 0.1

ต้นแบบเกมเว็บแนว 2D Turn-Based Artillery พร้อมเมนูภาษาไทย

## วิธีเปิดเล่น
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome, Edge, Safari หรือ Firefox
3. เลือก “เข้าสู่สนามรบ” แล้วปรับมุมยิง/แรงยิง จากนั้นกด “ยิง!”

## สิ่งที่มีในต้นแบบ
- หน้าหลักและเมนูภาษาไทย
- หน้าตัวละคร / คลังไอเทม / ร้านค้า
- ภารกิจประจำวันแบบตัวอย่าง
- หน้ากิลด์ / จัดอันดับ / ตั้งค่า (UI ตัวอย่าง)
- สนามฝึกซ้อม 2D ยิงผลัดตากับคู่ต่อสู้ AI แบบพื้นฐาน
- ระบบ Gold, ซื้อของ, รางวัล และความคืบหน้าภารกิจแบบ session

## ขอบเขตที่ยังไม่ใช่ระบบออนไลน์จริง
เวอร์ชันนี้เป็น Front-end prototype เพื่อทดสอบหน้าตาและ gameplay loop เท่านั้น
ยังไม่มีบัญชีผู้ใช้จริง, ฐานข้อมูล, matchmaking, multiplayer network, anti-cheat,
ระบบชำระเงิน หรือเซิร์ฟเวอร์จัดอันดับจริง

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html`, `style.css`, `game.js`
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch → `main` → `/ (root)` → Save
5. รอ GitHub สร้าง URL สำหรับเข้าเล่น

## หมายเหตุด้านทรัพย์สินทางปัญญา
นี่เป็นแฟนคอนเซปต์/ต้นแบบที่ใช้ชื่อเพื่ออธิบายแนวทางเท่านั้น ไม่ใช่เกมหรือบริการอย่างเป็นทางการ
ควรใช้ชื่อ โลโก้ ตัวละคร ภาพ เสียง และไอเทมต้นฉบับของตนเองในการเผยแพร่เชิงพาณิชย์
